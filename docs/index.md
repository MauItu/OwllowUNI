# Owllow

**Sabiduría para tus finanzas** 🦉

Owllow es una aplicación de registro de finanzas personales: cuentas, gastos, ingresos,
presupuestos, deudas, metas de ahorro y gastos compartidos. Sin anuncios y sin rastreadores.
